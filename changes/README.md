# Changes

每个非平凡变更是一个完整、可执行、可审计的 OpenSpec 工作区。

```text
change.yaml       唯一状态、Gate 和外部关联源
context.md        目标、非目标和修改边界
proposal.md
specs/
design.md
tasks.md
implementation/
validation/
reviews/
evidence/
```

- `active/`：正在设计、评审或实现；
- `archived/`：已完成、取消或被替代；
- `_template/`：由 `tools/new_change.py` 使用的标准模板。
