# Grill With Docs

1. Read `AGENTS.md`, relevant product assets, domain files and Decisions.
2. Identify concrete ambiguities, contradictions and missing acceptance outcomes.
3. Ask only questions that materially change the Spec or implementation boundary.
4. Record resolved facts, unresolved questions, non-goals and affected domains in the Change proposal.
5. Do not invent domain terminology or silently override an existing Decision.
