# Requirement Development Skill Routing

| 阶段 | Skill | 主要产物 |
|---|---|---|
| 需求模糊 | `grill-with-docs` | 澄清结论、开放问题、术语和 Decision |
| 领域语言变化 | `domain-modeling` | glossary、领域模型、Decision |
| 需求成形 | `to-spec` | `proposal.md`、`specs/`、测试 Seam |
| Spec 已批准 | `to-tickets` | `tasks.md`、纵向切片和阻塞关系 |
| 任务实现 | `implement` + `tdd` | 代码、测试和执行证据 |
| 实现完成 | `code-review` | Standards 与 Spec 双轴报告 |
| Bug/性能问题 | `diagnosing-bugs` | 可复现闭环、根因、回归测试 |
| 模块设计 | `codebase-design` | 深模块、接口和 Seam 设计 |

非平凡需求不得跳过 Spec 评审直接进入实现。
