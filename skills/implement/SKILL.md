# Implement

1. Read `AGENTS.md`, the Change, affected domain files and relevant Decisions.
2. Select one ready Task and confirm its approved test Seam.
3. Invoke the TDD discipline and implement only the Task scope.
4. Update Task status and preserve commands, results and important decisions in `evidence/`.
5. Stop and surface conflicts instead of weakening domain invariants, tests or acceptance criteria.
