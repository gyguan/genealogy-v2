# 领域资产

本目录是业务语义、领域边界和不变量的权威来源。

## 当前领域骨架

- `person-registry/`：人物稳定身份与姓名；
- `family-and-kinship/`：血缘、家庭和谱籍关系；
- `lineage-organization/`：宗、派、支、房、户；
- `source-and-evidence/`：来源、引文、主张与证据；
- `genealogy-project/`：修谱项目、采集与协作；
- `publication/`：出版快照、谱书版本与交付。

每个领域后续统一包含：模型、规则、用例、契约、示例、Eval 和领域级 `AGENTS.md`。
