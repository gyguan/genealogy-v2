# Code Review

Review along two axes:

1. **Standards**: repository rules, domain invariants, security, maintainability and test quality.
2. **Spec**: missing behavior, incorrect behavior, scope creep and traceability gaps.

Classify findings as blocking or non-blocking, reference exact files or requirements, and save the result in the Change evidence directory. Do not approve while blocking findings remain unresolved or explicitly accepted.
