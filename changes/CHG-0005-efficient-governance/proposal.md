# Proposal
## 背景与问题
校验入口分散、Capability 有重复投影、Change 创建成本高，评审可晚于合入。
## 关联产品能力
不改变业务能力。
## 目标
建立唯一检查入口、最小上下文、参数化 Change、严格产品校验和当前 Head PR 治理。
## 非目标
不直接修改 GitHub 服务端 Ruleset，不引入重型流程引擎。
## 范围与影响领域
仓库工具、模板、CI 和贡献规则。
## 关联 Decision
无。
## 风险
Bootstrap PR 本身尚未有新门禁；通过显式一次性例外并在仓库记录控制。
## 成功标准
本地与 CI 同一命令；重复投影删除；占位标题失败；后续 PR 当前 Head Review 和线程状态被校验。
