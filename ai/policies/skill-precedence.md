# Skill 优先级

1. 用户当前明确要求；
2. 根 `AGENTS.md`；
3. 当前 Change 的 `change.yaml` 和 `context.md`；
4. canonical 领域规则与 Accepted Decision；
5. `skills/` 中项目适配 Skill；
6. 外部 Skill；
7. `reference/`。

上游 `CONTEXT.md` 映射到本仓 `domains/glossary.yaml`、`domains/context-map.yaml` 和领域 Manifest；上游 `docs/adr/` 映射到 `decisions/`；上游直接写 Issue 的 Spec 必须先落到 Change。
